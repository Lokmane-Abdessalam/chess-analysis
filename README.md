# Chess.com to WintrChess Auto-Analyzer

**Chess.com to WintrChess Auto-Analyzer** is a Chrome extension that automates the export of your completed Chess.com matches to WintrChess for deeper analysis.

## Key Features

- **⚡ One-Click Export:** Adds a floating "⚡ Analyze on Wintr" button directly to completed game pages on Chess.com.
- **📜 Direct PGN Retrieval:** Extracts standard algebraic move notation directly from Chess.com's public game archives.
- **🚀 Auto-Pasting:** Launches WintrChess, fills out the move history, and starts match analysis automatically.

---

## Installation

1. Clone or download this repository.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the extension folder.

## Usage

1. Open any completed game on Chess.com.
2. Click the floating **⚡ Analyze on Wintr** button at the bottom-right corner.
3. The extension will automatically fetch the PGN, open `wintrchess.com/analysis`, paste the moves, and start the analysis.
